## Серверные действия остаются отдельно

Доступ к Firefox/панели REG.RU через компьютерные инструменты не предоставлен. Поэтому кодовые правки публикуются на основном портфолио, а для REG.RU передаётся новый полный архив. Настройки HTTP → HTTPS и www → основное имя, удаление ZIP на хостинге и назначение 404 не выполнены из этой сессии. `.htaccess` не добавляется и не перезаписывается: действующая конфигурация неизвестна.

Политика обработки данных не публикуется с незаполненными условиями. Фото мастеров и цены не подменяются. Внутренний прайс остаётся статическим; описание акций больше не называет его автоматически действующим прайсом Yclients.
