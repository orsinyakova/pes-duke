# Декоративные буквы первого экрана

В заголовке три акцента (И, О, U) отображаются встроенными SVG-контурами из исходного Pilowlava Regular. Они не используют SVG text, внешние изображения, сетевые запросы или JavaScript. Поэтому сбой загрузки файла Pilowlava больше не заменяет эти буквы системным шрифтом.

Контуры извлечены из исходного Pilowlava-Regular.otf; лицензия и авторство Pilowlava сохранены в index.html. Пропорции контуров сохранены. Высота всех трёх контуров нормализована к высоте прописных букв Anticva — 787/1000 em; нижняя граница стоит на общей базовой линии. Цвет наследуется через currentColor. SVG находятся внутри прежних анимируемых слов.

Исходные буквы остаются скрытым доступным текстом; SVG исключены из дерева доступности. У заголовка сохранено цельное доступное название.

Проверено: 320, 390, 768, 1024, 1440 px без горизонтального переполнения. Размер акцента равен размеру соседнего текста; высота SVG соответствует высоте прописных с округлением менее 0,01 px. В отдельной локальной копии с CSP font-src 'none'; script-src 'none' все три контура остаются видимыми. Проверка не заменяет тест на физическом iPhone.

Публикация этой правки: только основное портфолио. Перенос на pesdukegroom.ru отложен по просьбе заказчика до накопления остальных правок; тестовый стенд не обновляется.
