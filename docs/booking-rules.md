# Запись через Yclients

8 ноября 2026 Ольга попросила убрать выбор породы перед записью на груминг собак и по всему сайту предпочитать прямой переход в Yclients, поскольку сайт не синхронизируется с сервисом.

Все кнопки записи на главной и в каталоге ведут на `https://n1254086.yclients.com/`, без ID услуги или мастера. Выбор делается в актуальной форме сервиса. Ссылки «Все услуги и цены» в популярных услугах и обоих футерах также открывают Yclients. Внутренняя страница услуг остаётся доступна через навигацию; её прайс по-прежнему статический, автоматической синхронизации нет.

Из главной удалены модальное окно предварительного выбора, встроенный список пород/услуг с ценами, обработчики и относящиеся к ним стили. У карточек мастеров обновлены доступные подписи, чтобы они не обещали открытие конкретного профиля. Обычные ссылки работают без JavaScript, открываются в новой вкладке с `rel="noopener"`.

Эта инструкция заменяет прежние описания предварительного выбора и ссылок с ID в `popular-services-sources.md` и `team-sources.md`. При будущих изменениях сохранять прямую запись через общую форму Yclients, пока Ольга не задаст иной сценарий. Публикуется только основная версия портфолио; тест и REG.RU не обновляются.
