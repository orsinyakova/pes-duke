# Pes Duke

Первый экран сайта груминг-салона Pes Duke.

HTML, CSS и JavaScript находятся в `index.html`. Логотип и шрифты встроены, фоновое видео находится в `assets/grooming-background.mp4`, GSAP загружается с cdnjs.

Откройте `index.html` в браузере или запустите статический сервер из папки проекта.

При включённой настройке «Уменьшить движение» анимация и автозапуск видео отключены.
