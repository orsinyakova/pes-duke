# Pёs Duke

Сайт груминг-салона Pёs Duke: первый экран, популярные услуги, галерея работ «До / после», команда, программа лояльности, отзывы и контакты.

HTML, CSS и JavaScript — в `index.html`; изображения, шрифты, резервная копия GSAP и видео — в `assets/`.

Основная версия: https://portfolio.sinyakova.art/pes-duke/. Каталог услуг — `services.html`. Публикация через GitHub Pages из ветки `main`, без сборки.

Запись со всех страниц ведёт сразу в общую форму Yclients, без локального выбора породы, услуги или мастера. Ссылки «Все услуги и цены» также ведут в сервис. Внутренний каталог остаётся статическим; автоматической синхронизации нет. Правило для будущих правок — в `docs/booking-rules.md`.

В галерее девять работ: семь пар «до / после» и два отдельных снимка результата. Оригиналы фотографий и промежуточные файлы остаются в локальном `working-assets/` и не публикуются. Источники и согласованные подписи — в `docs/before-after-sources.md`.

Галерея заранее загружает соседние работы и переключает кадры вместе после декодирования. Код — `assets/works-gallery.js`; проверка загрузок и быстрых кликов — `node --test tests/works-gallery.test.cjs`. Подробности в `docs/gallery-loading.md`.

Хедер на обеих страницах после прокрутки превращается в закреплённую светлую капсулу, а при возврате к началу восстанавливает исходный вид. Общие стили и поведение — `assets/header.css` и `assets/header.js`. Высота исходного хедера сохранена, чтобы каталог не сдвигался; отступы якорей учитывают капсулу. При уменьшении движения появление без анимации.

Для компьютера и телефона используются отдельные облегчённые видео H.264 с быстрым стартом. Пока видео не готово или недоступно, показывается постер. Текст и кнопки доступны независимо от загрузки видео и анимации. При включённом уменьшении движения остаётся статичный фон.

На телефоне видео заполняет фон всей hero-секции. Заголовок и кнопки расположены поверх ролика с затемнением для читаемости; описание и проверка — в `docs/mobile-hero-video.md`.

Исправления поиска, фавикон, метаданные и файлы для индексации — в `docs/site-quality-fixes.md`. Canonical указывает рабочий домен `pesdukegroom.ru`. Для обновления REG.RU нужен полный архив с корневыми `favicon.*`, `robots.txt` и `sitemap.xml`, а не только HTML и `assets`.
