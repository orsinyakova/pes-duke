# Pes Duke

Сайт груминг-салона Pes Duke: первый экран, популярные услуги, галерея работ «До / после», команда, программа лояльности, отзывы и контакты.

HTML, CSS и JavaScript — в `index.html`; изображения, шрифты, резервная копия GSAP и видео — в `assets/`.

Основная версия: https://portfolio.sinyakova.art/pes-duke/. Каталог услуг — `services.html`. Публикация через GitHub Pages из ветки `main`, без сборки.

В галерее девять работ: семь пар «до / после» и два отдельных снимка результата. Оригиналы фотографий и промежуточные файлы остаются в локальном `working-assets/` и не публикуются. Источники и согласованные подписи — в `docs/before-after-sources.md`.

Для компьютера и телефона используются отдельные облегчённые видео H.264 с быстрым стартом. Пока видео не готово или недоступно, показывается постер. Текст и кнопки доступны независимо от загрузки видео и анимации. При включённом уменьшении движения остаётся статичный фон.
